# Magalie Joly Allaitement 64

Export statique complet, prêt à être déposé à la racine du dépôt GitHub `magalie-joly-allaitement`.

## Mise en ligne

1. Décompresser le ZIP.
2. Déposer le contenu du dossier à la racine du dépôt GitHub.
3. Conserver le dossier `.github/workflows/`.
4. Dans GitHub : **Settings → Pages → Source : GitHub Actions**.
5. Pousser sur la branche `main`.

Le workflow `.github/workflows/deploy-pages.yml` publie automatiquement le site à chaque mise à jour de `main`.

## Structure

- Pages HTML et dossiers de routes
- `site.css` et `site.js`
- `assets/` : images, illustration smartphone et polices locales
- `favicon.svg`, `robots.txt`, `sitemap.xml`
- `.nojekyll`
- Workflow GitHub Pages
